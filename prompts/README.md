# Prompt 用途

| 编号 | 用途 |
| --- | --- |
| S01 | 根据单条学生工作日志生成具体的肯定意见和改进建议，供直属评价人核对。 |
| S04 | 从指定部门的阶段日志中归纳工作进展和困难。 |
| S05 | 根据部门月度日志提出有依据的人员调整或奖励建议。 |
| S06 | 从部门月度日志提取实际提出且有来源记录的 idea。 |
| S07 | 从部门月度日志筛选有依据的重点谈话对象和主题。 |
| S08 | 从团队周度日志提炼可复用的公共技术建议。 |
| S09 | 从团队周度日志提出有共同需求和来源依据的公共培训建议。 |
| S10 | 汇总各部长确认后的部门结果，形成团队摘要。 |
